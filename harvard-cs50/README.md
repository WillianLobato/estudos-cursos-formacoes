## 📖 Sobre o Curso

O **CS50's Introduction to Programming with Python (CS50P)** é o curso introdutório de programação em Python da **Universidade de Harvard**, voltado à escrita, leitura, depuração e teste de código com foco na resolução prática de problemas.

* **Conteúdo Técnico:** Funções, variáveis, condicionais, loops, tratamento de exceções, testes unitários, bibliotecas, manipulação de arquivos (*File I/O*), expressões regulares (*Regex*) e Programação Orientada a Objetos (OOP).
* **Ambiente & Prática:** Exercícios práticos (*Problem Sets*) desenvolvidos em ambiente VS Code na nuvem (`cs50.dev`) com validação automatizada e projeto final.
* **Formação Internacional:** Aulas, notas técnicas e desafios ministrados em inglês pelo Prof. David J. Malan.
