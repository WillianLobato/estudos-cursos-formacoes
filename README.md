## 🎯 Sobre este Repositório

Bem-vindo(a)! Este repositório foi criado com o objetivo de **centralizar e organizar toda a minha jornada de aprendizado prático** em tecnologia. 

Para manter meu perfil no GitHub limpo e focado em projetos completos e aplicações principais, reuni aqui todos os exercícios, desafios de código, anotações, laboratórios práticos e projetos guiados desenvolvidos durante **cursos, formações, bootcamps e mentorias**.
